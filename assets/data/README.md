# サイトデータの編集ガイド

このフォルダの JSON ファイルが、サイトに表示されるデータの**唯一の編集場所**です。
ここを編集して `main` に push するだけで、**トップページと採用ページの両方に自動反映**されます。
HTML や JavaScript を触る必要はありません。

| ファイル | 内容 | 反映先 |
|---|---|---|
| `voices.json` | 社員の声(メンバー一覧) | トップページ「社員の声」+ 採用ページ「社員の声」(カード・モーダルとも自動生成) |
| `stats.json` | チャートデータ(従業員数の推移・スキル割合) | トップページ「数字で見るトライテック」+ 採用ページのチャート(凡例も自動生成) |

## 社員の声: 人を追加する (`voices.json`)

`members` 配列に、以下の形のオブジェクトを1つ追加するだけです。
**配列の並び順 = サイトでの表示順**です。入れ替えたい場合は順序を並べ替えてください。
削除したい場合はそのオブジェクトごと削除します。

```json
{
  "id": "yamada",
  "initial": "TY",
  "name": "",
  "role": "システムエンジニア／バックエンド担当",
  "catch": "カードに表示される一言キャッチ",
  "avatarSvg": "<svg viewBox=\"0 0 100 100\" xmlns=\"http://www.w3.org/2000/svg\" stroke=\"#00ffcc\" stroke-width=\"2\" fill=\"none\"><circle cx=\"50\" cy=\"38\" r=\"18\"/><path d=\"M 25 95 Q 25 70 50 65 Q 75 70 75 95\"/></svg>",
  "chapters": [
    { "title": "入社を決めた理由と入社後のギャップ", "body": "1段落目の本文。\n\n2段落目の本文。" },
    { "title": "具体的な仕事内容と一日の流れ", "body": "..." }
  ]
}
```

### 各項目の意味

- **id** — 半角英小文字のユニークな名前(例: 苗字のローマ字)。他のメンバーと重複しないこと
- **initial** — カードに大きく表示されるイニシャル2文字
- **name** — 氏名。空文字 `""` にすると名前は表示されません(現行は全員非公開)
- **role** — 職種・役割(カードとモーダルに表示)
- **catch** — カードのキャッチコピー(1行)
- **avatarImage** — 顔写真・イラスト画像を使う場合の画像パス(省略可)。
  例: `"avatarImage": "/assets/images/voices/yamada.jpg"`
  - 画像は `assets/images/voices/` に置く(推奨: 正方形 240×240px 以上、jpg/webp、100KB以下)
  - **指定すると avatarSvg より優先**され、カード・モーダルとも円形にトリミング表示されます
  - 全員一斉に写真へ切り替える場合も、各メンバーにこの1行を足すだけでOK
- **avatarSvg** — 線画イラストのSVG(avatarImage が無い場合に使用)。既存メンバーのものをコピーして調整するのが簡単です。
  **注意: SVG内のダブルクォートは `\"` にエスケープが必要**
- **chapters** — インタビュー本文。`title` + `body` の配列(何章でも可)。
  **改行は `\n`、段落の区切りは `\n\n`** と書きます(実際の改行文字は使えません)

### 編集後の確認

1. JSON構文が正しいか不安な場合は https://jsonlint.com/ に貼り付けてチェック
2. push 後にトップページ下部「社員の声」と 採用ページ「社員の声」を確認

## チャート: 数字を更新する (`stats.json`)

### 従業員数の推移 (`employees`)

```json
{ "y": "2027", "v": 45, "note": "予定" }
```
- **y** — 横軸ラベル(年)
- **v** — 人数
- **note** — 省略可。「予定」など棒の注記

※ 縦軸の最大値はグラフ側が40で固定のため、40名を超える場合は開発者に相談してください。

### スキル割合 (`skills`)

```json
{ "label": "WEB開発", "value": 40, "color": "#E07830" }
```
- 合計が **100** になるようにしてください
- **color** — ドーナツと凡例の色(16進カラーコード)
