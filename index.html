// WHY TRITECH

トライテックを選ぶ5つの理由

POINT 01

エンジニア社長の考える、エンジニアファーストの報酬設計

売上の高い割合をエンジニアへ還元する仕組みを採用。市場価値を正しく反映した給与水準を実現し、スキルアップや案件単価の向上が直接収入に繋がります。昇給制度も完備しており、頑張りが見える化される文化です。

POINT 02

自分で選べる案件・技術スタック

「やりたいことがある」「この技術を伸ばしたい」という希望を最優先に案件をマッチング。金融・製造・EC・SaaS など多様な業界の上流〜運用フェーズまで、キャリアプランに合わせて選択できます。希望と合わない案件は断ることができます。

POINT 03

成長を止めないラーニング環境

社内勉強会、資格取得支援(費用全額補助)を提供。また現役エンジニアがあなたのメンターとなり定例1on1を開催し、あなたのキャリアプランを全面的に支援します。

POINT 04

エンジニアを不安にさせない透明性

参画案件の単価はもちろん、あなたの報酬の算出根拠も開示します。現場で活躍するエンジニアが不安にならないように、常に透明性を意識した会社運営をしています。

POINT 05

充実した福利厚生・働き方の柔軟性

リモートワーク対応案件多数・フレックスタイム制・社会保険完備・交通費支給（上限3万円）など、安心して長く働くための制度を整備。「エンジニアとして、人として」尊重される職場環境を追求しています。

// PROJECT CHOICE

やりたいこと、やれる場所、
すべて自分で選べる。

― 100%案件選択制 ―

「興味のない分野にアサインされて、ただこなすだけの日々になってしまった」

「キャリアを考えると本当は別の工程に挑戦したかったのに、配属は会社都合だった」

そんな経験をしたことがあるエンジニアにこそ、トライテックの"100%案件選択制"を知ってほしいと思っています。

私たちは、10000件以上の案件から、あなたが本当にやりたい案件を一緒に選びます。

どんな希望もまずは遠慮なく話してください。会社都合の強制的なアサインは一切ありません。

やりたいことが、やれることになる。それがトライテックのスタンダードです。
